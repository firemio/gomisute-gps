# 女川町のデータ: Opus のエージェント2人の独立した読みで作る

2026-10-18 作成。[比較実験 2](llm-baseline-hard.md) で、最上位の AI (Claude Opus 5.5) でも外したことが1つあった:
女川町が **2026年10月1日に分け方を変えた** (ペットボトルのキャップ・ラベル、色つきトレイ、発泡スチロールなどが「赤かご」へ) のに、
4月に印刷された町民カレンダーの分け方で答えた。そこで、女川町の 2026年度のデータを、日付と分け方の有効期間つきで作った。

## 元にした公式資料

- 令和８年度 おながわ町民カレンダー (PDF 32ページ。燃やせるごみは月ごとの日付の表の「黄色の日」「水色の日」の色、
  資源ごみ・燃やせないごみ・粗大ごみは行政区のまとまりごとの表。結合したマスあり)
- 町の「環境・ごみ」のページ、2026年10月からの「家庭ごみの分け方・出し方」一覧表、ごみ分別事典、プラスチックの分別の資料、中心部の行政区割図

## 作り方 ([build_onagawa.py](../build_onagawa.py)、読み取りは Claude のワークフロー)

1. **構成**: 2人が別々に、凡例 (行政区と色の組)、表の行と列の見出し、出し方・分け方 (2026-10-01 の前後)、地名と行政区の対応を読む。
   3人目が2人の結果を突き合わせ、違う所は資料を開いて決める (例: 列の見出しの印字どおりの表記、10月より前のプラスチック製容器包装の扱い)
2. **日付**: 2か月ずつ、2人が別々に、燃やせるごみの色のマスと、表のすべての行 × 列のマスの日付を読む (2か月ずつ6組 × 2人 = 12エージェント)
3. **突き合わせ**: 2人の読みをマスごとに機械で比べ、違うマスだけ3人目が資料で確かめて決める

| | 結果 |
|---|---|
| 日付のマス (12か月 × (色の組 3 + 6行 × 4列) = 324マス) | **2人の読みが全部一致** (食い違い 0。3人目の出番なし) |
| 日付 | 324マスの中に 742件 (燃やせるごみ: 黄色の日・水色の日 各103日。資源ごみ・燃やせないごみ・粗大ごみ) |
| 燃やせるごみの曜日 | 黄色＝月・木、水色＝火・金。色の無い月・火・木・金は 12/31 と 1/1 だけ (年末年始)。祝日も色がつく (収集あり) |
| 分け方 | 40件: 年度を通して同じ 19件、9月30日までの 9件、10月1日からの 12件。10月1日の前後で対になる品目は 7つ (キャップ・ラベル・色つきトレイ・発泡スチロールなど)。10月1日の一覧表で初めて載った品目 (プラスチック製品・内部が銀色の紙パック・パソコンなど) と、9月30日で無くなった書き方 (プランター・バケツは入れない、など) もある。変わった品目について2人の読みは一致 |
| 出す時刻 | 「ごみは収集日の朝8時までに出して下さい」(町の「環境・ごみ」のページ)。金沢市 (午前8時30分) とは違う |
| エージェント | 15 (構成 2 + 突き合わせ 1 + 日付 12)。約29分 |

## 別の読みとの照合

比較実験 2 の正解 (別の2人のエージェントが、このデータづくりとは別に読んだもの) の女川町 6問 (年末の 12/31、祝日の 11/23、
4品目が重なる 12/14 などを含む) と、このデータの答えが **6問とも一致** した。

## 答え方 ([onagawa.py](../onagawa.py))

- 住所・地名 → 行政区: 「女川町」のあとがカレンダーの凡例の行政区の名前そのもの (「女川町針浜」、「女川町清水区」「女川町清水行政区」も可) のときだけ確定 (`ok`)。
  「宮城県牡鹿郡」「〒986-…」は付いていてもよく、「女川針浜」のように「町」を略した形も女川町として引く (MCP サーバー)。町名の無い「針浜」は金沢市の住所として探し、見つからなければ「女川町針浜」で引くよう添える。
  地名 (大字など。「浦宿浜」「高白浜」) からは、町の資料 (行政区割図・統計書・避難所一覧) で推定した行政区を候補にして `ambiguous` で返し、
  凡例の行政区を聞き返す。どの候補でも同じ日は `consensus` で返す (例: 浦宿浜 → 大沢・浦宿全区。どちらも資源ごみは同じ欄)
- 江島地区は、カレンダーに日付が載っていない (「燃やせるごみは月曜日と金曜日」「資源ごみ等は区長さんなどを通じ別途お知らせ」) ので、
  日付ごとの答えは出さず、その文を引いて伝える
- 震災後の新しい町名 (黄金・大道・海岸通りなど) は、どの行政区に入るか公式資料に無いので、行政区を聞き返す
- 分け方 (`garbage_sorting`): 日付の時点で有効なルール (`matches`) を返し、ほかの期間のルール (`other_periods`) も添える
  (例: 2026-10-20 のペットボトルのキャップ →「赤色のかご」、なお 9/30 までは「灰色のかご」)。
  品目名の表記ゆれ (蓋・フタ・キャップ、付き・ついた、トレー・トレイ、てんぷら・天ぷら) はそろえ、分別表の品目名そのもの (括弧つきも) と括弧の中の例に当てる。
  問いが長い品目名の一部にすぎないとき (「たばこ」⊂「加熱式たばこ」、「コップ」⊂「割れたコップ」) は確定せず、近い品目を並べて聞き返す。確定したときも、同じ語を含む別の品目で出し先が違うもの (「紙パック」に対する「内部が銀色の紙パック」) は「ただし…」と添える。材質で出し先が変わる品目 (バケツ・ハンガー・スプーンなど) は、
  材質が書かれていなければ `ambiguous` で聞き返す。分別表に無い品目・出し先が書かれていない品目は `unresolved`、
  データの期間 (2026-04-01〜2027-03-31) の外の日付は `out_of_range`

## 限界

- 正解づくりと同じく、読んだのは Claude のエージェントで、人間の目では確かめていない
- 地名 → 行政区の対応は町の資料 (行政区割図・統計書など) からの推定を含む (確かさ「likely」)。番地まで分かれる所は表せていない
- 分け方は、変わった品目と主な品目だけ (40件)。分別事典のすべての品目ではない
