# 比較実験 2: カレンダーが PDF・画像だけの自治体で、ウェブ検索だけの AI はごみの日を答えられるか

2026-10-17 実施。[金沢の実験](llm-baseline.md)では、ウェブ検索だけの AI (Claude Opus 5.5) が 28問すべてに正しく答えました。
ただし金沢は、区域表もカレンダーも HTML の表で、住所から地区を探すページもある、AI にとって答えやすい自治体です。
今回は、カレンダーが PDF や画像の中にしかない自治体で同じことを測りました。軽いモデル (Claude Haiku 5.5) にも同じ問題を聞きました。
生データ (問題・正解と出典・2つのモデルの回答全文・使った道具・付随情報の照合結果) は [llm-baseline-hard.json](llm-baseline-hard.json) にあります。

## 選んだ自治体

市・町・村を混ぜ、地方も分けて 5つ選びました。どれも、ごみの日を HTML の表やテキストでは公開していません。

| 自治体 | 規模 | カレンダーの形 | PDF から文字として取れるもの | 住所 → 地区 |
|---|---|---|---|---|
| 新潟県村上市 | 市 (約5万人) | 地区別の PDF 13枚。燃やすごみはマスの色だけ、プラはアイコン画像だけ | 日付の数字と一部の品目名だけ。燃やすごみの日とプラの日は取れない | 荒川・神林は大字の一覧あり (HTML)。村上地域 (村上地区 / 岩船・瀬波…) は町名の一覧がない |
| 北海道旭川市 | 市 (約31万人) | 11パターンの A2 PDF (8〜9MB) と月別の A4 PDF。品目はマスの色と図形にした文字 | なし (0文字) | HTML の地域→パターン表。条・丁目・番で分かれる町あり |
| 宮崎県宮崎市 | 市 (約40万人) | エリア別の A3 PDF。画像1枚と図形にした文字。「第5週は収集しません」などの規則と、月の中の注記 | なし (0文字) | PDF の町名→エリア表。国道の東西で分かれる町、橘通西 (北A) と橘通東 (北B)。清武は自治会名で分かれ、住所では決まらない |
| 宮城県女川町 | 町 (約5,600人) | ごみ専用のカレンダーはない。32ページ・8.4MB の「町民カレンダー」(原子力・税・行事の暦) の中に、燃やせるごみは地区の色 (黄・水色)、資源ごみは別ページの表 | 日付と六曜だけ。表の2桁の日付は文字化けする (例「8 ⨬」= 8日・22日) | 行政区の名前だけ。住所 (大字) との対応表はない |
| 茨城県東海村 | 村 (約3.8万人) | スキャン画像1枚の日割表 PDF (地域ごとの日付の表)。同じ表の PNG も村の検索ページにある | なし (0文字) | 住居表示→地域の対応表も画像。「舟石川1 または 舟石川2※ (詳細は電話)」のような行がある。地図は「目安」 |

人口はおおよその値です。旭川市と宮崎市はアプリ「さんあ〜る」でもカレンダーを配っていますが、PDF も公開しています。

## 方法

- **問題 30問** (各自治体 6問)。規則どおりでない日をわざと多く入れました。

  | 種類 | 例 |
  |---|---|
  | 色だけで示される日 | 村上市三之町の燃やすごみ (マスが水色なだけ) |
  | 地区を取り違えやすい住所 | 村上市緑町 (場所は瀬波だが「村上地区【緑町含む】」のカレンダー)、村上市岩船駅前 (村上地域の岩船ではなく神林南部)、旭川市永山9条2丁目5番 (1番だけ別パターン)、宮崎市橘通西 / 橘通東 |
  | 祝日 | 祝日に収集する日 (旭川 11/23・1/11、女川 11/23、東海村 11/3・11/23)、祝日の分を翌日に回す日 (村上 1/11 → 1/12) |
  | 年末年始 | 収集が休みの日 (旭川 12/30・1/4、宮崎 12/30、女川・東海村 12/31、村上荒川 1/2(土))、年末だけの収集日 (村上 12/30(水)) |
  | 規則の例外 | 第5週は古布・古紙を集めない (宮崎 10/30・12/29)。ただし「1月1日の代わりに1月29日は古布・古紙を収集」(宮崎北A) |
  | 品目が重なる日 | 女川高白 12/14 (燃やせる＋資源ごみ全部＋燃やせない)、宮崎南A 11/16 (不燃・金属・古布・古紙) |

- **正解**: 1人が公式の PDF を拡大した画像 (月ごと・表ごとに切り出して約2〜3倍) で読み、別のエージェントが、その答えを見ずに同じ問題を公式ファイルから読みました。
  30問すべてで 2人の答えが一致し、全部を使いました。1人目の読み違い 1件 (村上 11/23 の薄い水色) は 2人目の読みで気づきました (問題には使っていない日)。
  地区は自治体の表で決めました。村上地域だけは町名の一覧がないので、カレンダーの表題 (「緑町含む」) と市の国勢調査の地区別表で決めました。
- **答える側**: 1問ずつ別々のエージェントに、利用者の言葉で聞きました (例:「新潟県村上市大町 に住んでいます。2027年1月12日(火)にはどのごみを出せますか？」)。
  Opus 5.5 と Haiku 5.5 に同じ 30問を 1回ずつ聞きました。手元のデータや gomisute-gps は使わせていません。
- **道具の条件**: 使えるのはウェブ検索 (WebSearch) とページの取得 (WebFetch) だけです。
  ただしこの環境の WebFetch は PDF の中身を返しません (村上市の PDF で試すと、凡例も日付も取れなかった)。代わりに PDF をファイルに保存するので、
  **保存されたそのファイルを Read で開いて、ページを画像として見ることだけ** を許しました。一般向けの AI が PDF を開いて見られる状態に近い条件です。
  60件の記録を調べ、Read で開いたのが WebFetch の保存したファイルだけだったことを確かめました (画面表示用の道具を 1回呼んだ回答が 2件あるが、答えには関係しない)。
- **採点**: その日に出せる品目の組み合わせが正解と同じか、地区が合っているか。金沢と違い「分からない」と答えを出さない回答があったので、
  「答えられず」と「カレンダーを読めないまま古い資料から推測して当たった」を分けて数えました。
- **付随情報の照合**: 回答に含まれる付随情報 (前後の収集日、年末年始、出し方、袋、時刻、問い合わせ先など) を、自治体ごとに別の検証エージェント 1人が、公式の PDF とページで 1つずつ照合しました。

## AI がしていたこと

Opus 5.5:

- WebFetch で PDF を保存し、Read でページを画像として見て、マスの色・アイコン・凡例・月の中の注記を読んだ。
  村上の「1/11 は祝日で、燃やすごみは翌 12日(火)」、宮崎北Aの「1月1日の代わりに1月29日に古布・古紙」、
  女川の結合されたマス (その他の資源ごみと燃やせないごみが同じ日) も読み分けた
- 地区の取り違えを避けた。緑町は「村上地区【緑町含む】」、岩船駅前は神林南部 (「村上地域の岩船地区とは別」と明記)、
  永山9条2丁目は 1番だけ別パターン、春光台は「春光」とは別の地域、と書いた
- 東海村では、画像 1枚の PDF も読み、検索ページの PNG 版や住居表示の対応表 (画像) も使った
- 村上市では 3問で「確認を」と添えた (町名の一覧がないこと、色から読み取ったこと)

## 失敗の型 (具体例)

1. **PDF を読めず、答えを出さない** (Haiku 13問)。「PDFの中身を読み取れず」「推測では回答しません」として、問い合わせ先とアプリを案内して終わる。
   女川町 (32ページ・8.4MB の町民カレンダー) では 6問中 5問がこうなった。保存した PDF を Read で開いたのに「読めない」と答えた回もある。
   検索を何度も繰り返し、「検索の上限に達した」と書いた回答が 5件あった。
2. **色だけの印を読み落とす** (Haiku 1問、村上 1/12)。祝日 1/11 の燃やすごみが翌 12日(火) に回っているマス (薄い水色) を読み落とし、
   「1月12日(火)は収集がない日」「1月11日は祝日ですが、カレンダーに振替の表示はありません」「次の燃やすごみは1月8日(金)」と答えた。
   この回答どおりにすると、その日の燃やすごみを出しそびれる。60件の回答のうち、主回答が利用者を誤らせるのはこの 1件だけ。
3. **古い資料からの推測** (Haiku 6問)。カレンダーを読めないまま、平成25〜27年の町内会回覧、平成30年の年末年始の案内、令和7年度の表の断片を持ち出した。うち 4問はそこから曜日や収集の有無を推測した。
   旭川の 11/23 (「燃やせるごみの可能性が高い」) と 1/4 (「収集がない可能性が高い。出さないで」) は当たったが、根拠は今年度のカレンダーではない。
4. **前後の情報の誤り** (Haiku 3問)。主回答は正しいのに、付け足した情報が誤っている。
   村上荒川 1/2 では「直近の収集日は 1/8 のプラと 1/9 の燃やすごみ」とし、1/4・1/6 の燃やすごみと 1/5 のペットボトルを飛ばした。
   東海村 11/23 では「燃えるごみは指定袋または粗大ごみ処理券で」と書いた (処理券は粗大ごみ用で、粗大ごみはこの日に出せない)。
   女川 1/5 では、女川町にない「生ごみ」という区分を挙げた。
5. **年度の途中で変わった出し方を見落とす** (Opus 3問、女川)。日付はすべて正しいが、町民カレンダーの最終ページ (4月の印刷) の分け方をそのまま書いた。
   町は 10月1日から新しい分別表 (05_05.html からリンク) に変え、ペットボトルのキャップ・ラベル、色つきトレイ、発泡スチロールは赤かごに出すことになった。
   Opus は「キャップやふたは燃やせるごみへ」「色や模様のあるトレイは燃やせるごみへ」と答えた。Opus の付随情報の誤りのうち、出すものを誤らせうる 4件中 3件がこれ。
6. **品目名の言い換え** (Opus 1問、旭川 12/24)。「乾電池・蛍光管・ガス缶・ライター」を「乾電池・蛍光管・ガスボンベ・ライター」と書いた。
   市はガスボンベを処理困難物として、ごみステーションに出さないよう案内している。

## 公式の資料そのものでは住所から地区が決まらない所

正しく読めても、住所から地区が 1つに決まらない所がありました。この実験では、決まる住所だけを問題にしています。

- 村上市の村上地域: 「村上地区」と「岩船・瀬波 (緑町除く)・山辺里・上海府地区」に分かれるが、町名の一覧はどこにもない。朝日・山北も地区名だけ
- 宮崎市の清武: 「自治会名で表記してあります。住所表記ではありません」。旧宮崎市でも、国道10号・269号の東西で分かれる町がある
- 東海村: 住居表示の対応表に「舟石川1 または 舟石川2※」「舟石川3、百塚、豊白または白方※」とあり、※は「詳細は電話で」。地図は「目安」
- 女川町: 行政区の名前と住所 (浦宿浜、高白浜などの大字) の対応表がない
- 旭川市: 「地域のパターンがわからない場合は、クリーンセンターにお問い合わせください」

## 結論

- **カレンダーが PDF や画像だけでも、最上位のモデルが PDF をページの画像として見られれば、AI 単体で正しく答えられた** (Opus 30/30、地区も 30/30)。
  色だけの印、アイコン、スキャン画像、32ページの町の暦の中の表、月の中の注記も読んだ。金沢と同じく、ここでも「AI より正確」は gomisute-gps の売りにならない。
- **崩れたのは、モデルが軽いとき**。Haiku は 30問中 14問しか答えられず、13問は「分からない」で終わった。誤答は 1問だけだが、それは色の読み落としによる「収集なし」。
  形式が重い所ほど崩れた (女川 1/6、旭川 1/6)。村が同じ表を PNG でも出していた東海村は 5/6。
- **PDF を画像として見られない環境では、この 5自治体のカレンダーはそもそも読めない**。この環境の WebFetch は PDF の中身を返さなかった。
  文字として取り出せるのは、旭川・宮崎・東海村は 0文字、村上は日付と一部の品目名だけ (燃やすごみの日とプラの日は取れない)、女川は日付と六曜だけ。
  文字だけを読む AI は、答えを出せないか、取れた文字から誤って答えるはず (この条件では実際には聞いていない)。
- **手間は金沢と同じくらい重い**。Opus でも 1問あたり約10回の検索・取得と約9万トークン (金沢は約18回・約8万トークン)。Haiku は約17回・約9万トークンで、時間は Opus の倍以上かかった。
- **最上位のモデルでも、年度の途中の変更は拾えなかった**。女川町は 10月に分け方を変えたが、Opus は 4月に印刷された町民カレンダーの分け方を答えた。
- gomisute-gps のデータが実際に役立つのは次の所:
  1. **軽いモデル・文字しか読めない環境**: 地区と日付が機械で読める形であれば、PDF を開けるか・色を読めるかに左右されない
  2. **費用と時間**: 1回の問い合わせで、出典つきの答えが返る
  3. **公式資料では住所から地区が決まらない所** (村上地域、宮崎の清武、東海村の舟石川など): ここはウェブを読むだけでは AI もデータも確定できない。
     自治体から対応表をもらうなどして作れば、ウェブには無い価値になる
  4. **色や注記でしか書かれていない例外** (祝日の振替、年末だけの収集日、第5週の扱い、1/29 の振替): 軽いモデルが読み落とす所。データにしておけば読み落としが起きない
  5. **いつから有効かの管理**: 年度の途中で出し方が変わることがある (女川町の 10月の変更)。データに有効期間と出典の日付を持たせれば、古いページの情報を返さずにすむ
- 次に測るべきこと: PDF を文字でしか読めない環境で同じ問題を聞く、ウェブ検索なしで聞く、他社のモデルで聞く、同じ問題を何度か聞いてばらつきを見る。

## この実験の限界

- 5自治体・30問で、1問を各モデル 1回だけ聞いた。ばらつきは分からない
- 規則どおりでない日を多く選んだので、ふつうの日をランダムに聞くより難しい
- 「WebFetch が保存した PDF を Read で開いてよい」は、ウェブの取得だけより強い条件。Haiku の「答えられず」が多いのは、この手順 (保存ファイルを開く) を Haiku がうまく使えなかったことも一因で、
  PDF を直接読める別の環境では結果が違うかもしれない
- 正解は Claude のエージェント 2人の独立した読みが一致したもので、人間の目では確かめていない。付随情報の照合も Claude のエージェントが行った
- 村上地域 (M1〜M4) は公式の町名一覧がないので、地区はカレンダーの表題と国勢調査の地区別表で決めた。東海村の真崎・須和間には寮や隣の団地など例外がありうる
- 近畿・中国・四国の自治体は入っていない。答えたのは Claude のモデルだけ
